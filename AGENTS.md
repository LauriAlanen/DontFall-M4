# Project Rules

Read the project vision first: `~/Projects/DontFall/VISION.md`
([on GitHub](https://github.com/LauriAlanen/DontFall/blob/main/VISION.md)).
It covers the goal, architecture principles, and how to pace work (small,
digestible steps). Build and dev workflow: `~/Projects/DontFall/docs/development.md`.
Traps past agents hit: `~/Projects/DontFall/docs/lessons-learned.md`.
What runs where: `~/Projects/DontFall/docs/architecture.md`. A change here that
alters the architecture (a new thread or process, a link, a micro-ROS
entity, who owns what) updates that file too.

## Git commits

- NEVER add AI/tool attribution to commits: no "Generated with Devin",
  no "Co-Authored-By" bot trailers, no similar footers. Write plain
  commit messages only.
